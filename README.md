<h1 align="center">Games Cloudflare 2</h1>

These are the rest of the games for [BCHS Unblocked Games](https://github.com/tw31122007/BCHS-Unblocked-Games).

Cloudflare Pages allows 20,000 files in one project. The games that fit in that limit are in [HTML-Games-Cloudflare-Pages](https://github.com/tw31122007/HTML-Games-Cloudflare-Pages). This repository holds the games that did not fit.

Each game is in its own folder. [index.html](index.html) lists every game here and links to it with a relative path, so the list works on any domain this project is hosted on.
